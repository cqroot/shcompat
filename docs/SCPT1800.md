# SCPT1800: realpath command is not supported in older coreutils versions

## Problem

The `realpath` command may not be available on older systems or in older versions of coreutils, leading to portability issues.

## Example of problematic code

```sh
realpath ./some/path
```

## Correct code

Consider using `readlink -f` as a fallback, but note that it is not POSIX-compliant and may not be available everywhere:

```sh
readlink -f ./some/path
```

## Rationale

Scripts that require maximum portability should avoid relying on `realpath` unless you are certain it is available in your target environment.
