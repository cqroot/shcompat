# SCPT0300: curl command is missing ‐g or ‐‐globoff argument

## Problem

When using `curl`, globbing is enabled by default, which can lead to unexpected filename expansion if the URL contains special characters (e.g., `*`, `?`, `[]`).

## Example of problematic code

```sh
curl "http://example.com/file*[1-9].txt"
```

## Correct code

```sh
curl -g "http://example.com/file*[1-9].txt"
# or
curl --globoff "http://example.com/file*[1-9].txt"
```

## Rationale

The `-g` or `--globoff` option disables globbing, making the command safer and more portable.
