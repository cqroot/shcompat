# SCPT0700: grep command has a pattern with a stray backslash

## Problem

The `grep` command with a pattern containing a stray backslash (an unescaped backslash not followed by another backslash) may behave inconsistently across different versions of `grep`, potentially leading to unexpected results or errors. This issue arises starting from grep version 3.8.

## Example of problematic code

```sh
grep "pattern\ with\ backslash" file.txt
echo "----" | grep "\-\-\-\-"
```

## Correct code

Ensure all backslashes in the pattern are properly escaped:

```sh
grep "pattern with backslash" file.txt
# or if backslashes are needed for regex:
grep "pattern\\\\ with\\\\ backslash" file.txt

echo "----" | grep -- "----"
```

## Rationale

Different implementations of `grep` handle unescaped backslashes differently. For maximum portability, avoid stray backslashes in patterns unless you have verified the behavior on your target systems.
