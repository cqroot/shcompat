# SCPT1900: sed ‐‐sandbox is not supported in older sed versions

## Problem

The `--sandbox` option for `sed` is only available in newer versions. Using it on older systems will result in an error.

## Example of problematic code

```sh
sed --sandbox -e 's/foo/bar/' file.txt
```

## Correct code

Avoid using `--sandbox` unless you have verified that the target system's `sed` supports it.

## Rationale

For maximum compatibility, avoid non-standard or recently introduced options unless absolutely necessary.
